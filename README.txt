МЕДИС — учебный проект

В папке находятся:
- mis.html — HTML-разметка страницы;
- mis.css — оформление страницы;
- database.js — массивы с данными;
- renderer.js — функции создания DOM-элементов;
- app.js — запуск приложения и поиск.

Как запустить:
1. Распакуйте архив в отдельную папку.
2. Откройте папку в Visual Studio Code.
3. Запустите mis.html через расширение Live Server.
   Важно: не открывайте HTML двойным нажатием, так как используются JavaScript-модули.

Что реализовано:
- семантическая HTML-разметка;
- таблица с caption, thead, tbody и th scope;
- даты внутри time с datetime;
- CSS Grid и CSS-переменные;
- Google Fonts;
- данные отдельно от HTML;
- создание элементов через createElement и textContent;
- функции рендеринга принимают данные и возвращают DOM-элементы;
- поиск по пациенту и врачу.

Данные в database.js учебные. Их можно заменить на свои записи, сохранив названия полей.
